# 良策——基于 AxVisor 的实时智能工业控制操作系统

## 一、项目简介

本项目面向工业控制场景，基于 TGOSKits 与 AxVisor 构建轻量化虚拟化系统，目标是在同一平台中协同运行 Linux 智能计算环境与实时操作系统。系统计划通过标准 TCP/UDP/IP 网络完成 Guest 间数据交互，由 Linux 侧执行轻量神经网络推理，实时 Guest 执行控制任务，从而形成可测量、可复现的智能控制闭环。

项目当前以 QEMU AArch64 为主要验证平台，以 Linux 和 Zephyr 为主要 Guest，围绕实时性、资源隔离、Guest 通信和智能控制四条主线逐步推进。

## 二、项目目标

1. 在 AxVisor 上稳定运行 Linux 与实时操作系统 Guest。
2. 实现 vCPU、内存、设备和中断资源的明确分配与冲突检测。
3. 建立 Linux 与实时 Guest 之间的 TCP/UDP/IP 主通信链路。
4. 在 Linux Guest 中运行轻量神经网络模型，并向实时 Guest 下发控制结果。
5. 建立覆盖功能、实时性、稳定性和安全边界的可复现验证体系。

## 三、当前阶段成果

- 完成 TGOSKits、AxVisor、Rust、WSL2 和 QEMU AArch64 开发验证环境搭建。
- 完成 AxVisor 下 ArceOS 与 Linux 单 Guest 基线启动验证。
- 完成 Linux SMP2 单 Guest 运行验证，观察到双 vCPU 启动及对应处理器探针。
- 完成 Zephyr 原生与 AxVisor 单 Guest 周期任务验证，连续周期样本符合当前测试合同。
- 完成跨 VM CPU、固定物理内存、MMIO 和中断资源声明与冲突检查基础。
- 完成 Guest FDT 净化、固定 HPA 授权、Host carveout 和 allocator 排除基础。
- 完成 VM-local PL011 控制台、日志分流及相关静态和主机侧验证。
- 完成 ICPC v1 主机侧 C99 协议参考实现，支持 CRC32C、ACK、有限重传和去重窗口。
- 建立配置、脚本、测试、日志、状态文件和哈希校验组成的阶段性验证体系。

## 四、技术特点

- **虚拟化底座**：基于 AxVisor，实现面向 AArch64 的 Guest 管理与资源控制。
- **实时 Guest**：以 Zephyr 为当前实时操作系统基线，保留其他 RTOS 的扩展空间。
- **智能计算 Guest**：以 Linux 承载轻量神经网络推理和上层控制逻辑。
- **通信设计**：以 TCP/UDP/IP 作为最终 Guest 主通信方式，不以共享内存、裸 MMIO 或控制台替代网络链路。
- **安全边界**：对 CPU、HPA、MMIO、IRQ、Guest FDT 和 Host allocator 等关键资源实施显式检查和失败关闭。
- **验证体系**：区分静态合同、主机测试、单 Guest 运行和双 Guest 运行等不同证据等级，避免扩大测试结论。

## 五、当前阶段边界

本阶段已经完成开发环境、单 Guest 基线、Linux SMP2、Zephyr 周期任务、资源隔离基础、固定 HPA/Host allocator 观察以及 ICPC 主机协议合同。

以下内容仍在后续阶段推进，不属于本次已完成结论：

- Linux 与 Zephyr 双 Guest 同次稳定运行；
- 双 Guest 30 分钟以上稳定性验证；
- Guest 间真实 TCP/UDP/IP 连通；
- 通用 DMA 隔离证明；
- Guest 侧 ICPC 集成；
- 神经网络推理、实时执行与状态反馈组成的完整 AI 控制闭环。

后续将依次完成受控设备访问验证、双 Guest 启动与稳定性测试、虚拟网络链路、Guest 间 TCP/UDP/IP、ICPC 集成、轻量神经网络控制闭环以及综合性能与故障恢复测试，最终形成可独立复现的完整交付版本。
