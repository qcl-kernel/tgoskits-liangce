# 良策——基于 AxVisor 的实时智能工业控制操作系统

## 一、项目简介

本项目面向工业控制场景，基于 TGOSKits 与 AxVisor 构建轻量化虚拟化系统，目标是在同一平台中协同运行 Linux 智能计算环境与实时操作系统。系统采用 mediated VirtIO-net 和标准 TCP/UDP/IP 作为 Guest 间主通信链路，计划由 Linux Guest 完成轻量神经网络推理，由 Zephyr Guest 执行实时控制任务，形成可测量、可复现并具备安全降级能力的智能控制闭环。

当前主要验证平台为 QEMU AArch64，主要 Guest 为 Linux 与 Zephyr。项目按平台与隔离、实时性、Guest 网络和智能控制四条主线推进，并严格区分静态合同、单 Guest、双 Guest、Guest-IP、AI 闭环和实时 A/B 等不同证据等级。

## 二、项目目标

1. 在 AxVisor 上稳定并发运行 Linux 与实时操作系统 Guest。
2. 实现 vCPU、内存、设备和中断资源的明确分配、冲突检测与失败关闭。
3. 建立 Linux 与实时 Guest 之间的 TCP/UDP/IP 主通信链路。
4. 在 Linux Guest 中运行轻量神经网络模型，并向实时 Guest 下发控制结果。
5. 建立覆盖功能、实时性、稳定性和安全边界的可复现验证体系。

## 三、当前阶段成果

- 完成 TGOSKits、AxVisor、Rust、WSL2 和 QEMU AArch64 开发验证环境搭建。
- 完成 ArceOS、Linux SMP2 与 Zephyr 单 Guest 基线验证。
- 完成 Linux 与 Zephyr 双 Guest 同次启动验证，并取得一次 30 分钟共存观察包。
- 完成跨 VM CPU、固定物理内存、MMIO、中断和设备资源的声明、解析与冲突检查基础。
- 完成 Guest FDT 净化、固定 HPA 授权、Host carveout、VM-local 控制台和日志归属基础。
- 在 QEMU AArch64 双 Guest 会话中完成 mediated VirtIO-net 窄冒烟：Linux 与 Zephyr 均枚举虚拟网卡并使用固定 Guest IP。
- 完成 ICMP 100/100、UDP echo 100/100、TCP 连接建立和 ICPC codec 100/100 运行观察。
- 完成 Linux 发送 CONTROL、Zephyr 返回 ACK 与 STATUS、Linux 确认结果的双向 ICPC 链路观察；当前样本为发送 100、确认 85、丢失 15。
- 建立配置、脚本、测试、日志、状态文件、运行清单和 SHA-256 校验组成的阶段性验证体系。

## 四、技术特点

- **虚拟化底座**：基于 AxVisor，在 AArch64 平台上管理 Linux 与 Zephyr Guest。
- **资源控制**：通过解析后的设备图和资源申请机制管理 vCPU、HPA、MMIO 与 IRQ，并对冲突和陈旧状态失败关闭。
- **实时 Guest**：以 Zephyr 为当前实时操作系统基线，保留其他 RTOS 扩展空间。
- **智能计算 Guest**：以 Linux 承载轻量神经网络推理和上层控制逻辑。
- **通信设计**：使用 bounded mediated VirtIO-net 连接两侧 Guest，以 TCP/UDP/IP 和 ICPC 作为控制通信基础。
- **验证纪律**：每次运行绑定配置、镜像、会话身份、日志和状态文件；失败尝试保持不可变，不用低等级结果替代高等级结论。

本验收包生成于 2026-08-20。源码快照取自 `tgoskits-upstream-integration` 的本地分支 `contest/upstream-20260817`，基准提交为 `574d569bea21f6a47e9adde10bea4a5a270b96d0`。生成时该分支相对 `upstream/dev` 为 ahead 15、behind 39，并存在两个已跟踪构建产物改动；因此本包是当前本地工作树快照，不代表已经同步 2026-08-20 的最新官方 `dev`。

包内 P2 证据绑定其各自历史提交和 dirty source snapshot；P4 证据绑定 2026-08-19 对应运行会话。不同提交上的证据不能互相替代，也不能直接视为当前官方 HEAD 的回归结果。

- 通用 DMA 隔离或硬件 DMA 隔离；r24j 仅支持特定 VirtIO DMA effect 的窄观察。

- 完整 Linux 神经网络推理、IP 下发、Zephyr 动作执行与反馈组成的 AI 控制闭环。
- 满足正式样本量和场景矩阵的实时性能 A/B 改善。
- 组合压力、异常恢复和最终长期稳定性验收。
