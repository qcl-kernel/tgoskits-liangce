# 测试与证据说明

## 1. 说明

本文说明最终成果的验证层级、应提交工件和当前成果包的证据边界。测试结论必须绑定同一候选源码版本、运行环境、精确命令、退出码和文件哈希。

## 2. 证据层级

| 层级 | 主要内容 | 能证明 | 不能替代 |
|---|---|---|---|
| 文档与静态合同 | 需求、架构、接口、配置和负例规则 | 设计与约束明确 | 构建或运行 |
| 主机合同测试 | 协议、模型、状态机、validator 等主机测试 | 主机侧实现满足合同 | AArch64 目标或 Guest 运行 |
| 目标构建 | Rust/AArch64、Linux 应用、Zephyr 应用构建 | 指定目标可编译 | 虚拟机启动与网络 |
| 单 Guest 运行 | 单个 Guest 启动与身份工件 | 单 Guest 运行事实 | 双 Guest 并行 |
| 双 Guest 运行 | 两个 Guest 同时启动、资源与控制台绑定 | 双 Guest 同会话运行 | Guest IP |
| Guest IP | 双向 ICMP、UDP/TCP、抓包与协议事件 | Guest 间真实 IP 链路 | 智能控制闭环 |
| 控制闭环 | CONTROL、动作应用、STATUS 反馈和安全恢复 | 端到端控制链路 | 实时优化效果 |
| 实时对比与长稳 | 配对基线、分位数、故障和持续运行 | 量化改进及稳定性 | 未测试平台或泛化结论 |

## 5. 最终报告格式

每项测试报告至少包含：

- 测试编号、关联需求和预期判据；
- 上游基线、候选源码 40 位提交号及工作树状态；
- 主机、工具链、QEMU、Guest 镜像、配置和模型版本；
- 精确执行命令、开始结束时间、退出码；
- 原始工件路径或 URI、大小和 SHA-256；
- 实际结果、判据比较、证据层级；
- 失败原因、适用范围和未证明事项；
- 复核人及复核时间。

失败测试同样保留原始结果，不覆盖、不改写为通过。视频、截图、标记字符串或单个 CI 任务不能单独替代上述证据链。
