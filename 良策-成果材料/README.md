# 良策团队成果材料

## 1. 项目概述

- 团队名称：良策
- 团队成员：1 人
- 项目名称：基于 AxVisor 的混合关键系统智能控制原型
- 目标平台：QEMU AArch64
- 核心组成：AxVisor、Linux 智能计算 Guest、Zephyr 实时控制 Guest、软件中介 VirtIO-net、ICCP（仓库实现名 ICPC v1）通信协议、轻量神经网络控制器及可追溯测试体系

本项目面向工业控制场景，将智能计算任务与实时控制任务分别部署在 Linux 和 Zephyr Guest 中，由 AxVisor 提供虚拟机隔离、资源分配和内部网络连接。Linux 侧完成状态接收、模型推理和控制决策，Zephyr 侧完成周期控制、对象仿真、动作执行、状态反馈及失联安全保护。
